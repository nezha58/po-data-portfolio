# po-data-portfolio
Portfolio SQL, BPMN et UML – PO / BA orientée data
Ce repository présente des exemples de livrables que je réalise en tant que
Product Owner / Business Analyst orientée data et process.

## Contenu
- SQL : modélisation simple et requêtes analytiques orientées KPI métier
- BPMN 2.0 : modélisation de processus métier (AS-IS / TO-BE)
- UML : diagrammes d’analyse fonctionnelle

Les cas présentés sont inspirés de contextes réels (anonymisés) ou reconstituésà des fins de démonstration.
